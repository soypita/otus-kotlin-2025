# API

#### 1. Сущности
**Запись о книге (BookEntry)**

| Поле         | Бизнес-описание                               | Пример значения                   |
|--------------|-----------------------------------------------|-----------------------------------|
| `id`         | Уникальный ID записи                          | "018f6f5f-6a6b-7b4b-8b4b-1b1b1b1b1b1b" |
| `userId`     | Идентификатор пользователя                    | "user-123"                        |
| `bookTitle`  | Название книги                                | "Дюна"                            |
| `bookAuthor` | Автор книги                                   | "Фрэнк Герберт"                   |
| `status`     | Статус прочтения: "хочу прочитать", "читаю", "прочитана" | "READ" (прочитана)        |
| `rating`     | Оценка пользователя (от 1 до 5)               | 5                                 |
| `reviewText` | Короткий отзыв или заметка                    | "Великая книга о власти и экологии." |

#### 2. Бизнес-функции (методы)
**CRUD для записей о книгах**
1.  **`books.create`** - Создание новой записи о книге на "полке" пользователя.
    *   *Бизнес-правило*: Пользователь должен быть аутентифицирован.
    *   *Ограничения*: Название и автор не могут быть пустыми.

2.  **`books.read`** - Получение информации об одной книге по её ID.
    *   *Бизнес-правило*: Пользователь может запрашивать только свои записи.

3.  **`books.update`** - Обновление существующей записи.
    *   *Бизнес-правило*: Пользователь может обновлять только свои записи.
    *   *Ограничения*: Оценку (`rating`) можно выставить только для книги со статусом "прочитана".

4.  **`books.delete`** - Удаление записи с "полки".
    *   *Бизнес-правило*: Пользователь может удалять только свои записи.

5.  **`books.search`** - Поиск по книгам пользователя и получение списка.
    *   *Бизнес-логика*: Возвращает список книг пользователя с пагинацией. Если фильтры не заданы, возвращает все книги.
    *   *Фильтры*:
        *   `title`: по названию книги.
        *   `author`: по имени автора.
        *   `status`: по точному совпадению статуса.
        *   `rating`: по точному совпадению рейтинга.

#### 3. Бизнес-правила
1.  **Статусы книг**:
    *   `WANT_TO_READ`: Книга добавлена в список для будущего чтения.
    *   `READING`: Книга находится в процессе чтения.
    *   `READ`: Книга прочитана. Обязательный статус для выставления оценки.

2.  **Валидация оценки**:
    *   Оценка (`rating`) может быть целым числом от 1 до 5.
    *   Поле может быть `null`, если оценка не выставлена.

3.  **Ограничения доступа**:
    *   Все операции требуют аутентификации пользователя.
    *   Пользователь не имеет доступа к записям других пользователей.
