# Пользовательские истории (User Stories)

Эти истории описывают основные потребности пользователя в рамках MVP сервиса **BookShelf**.

---

### User Story 1: Добавление новой книги

**Как** пользователь,
**Я хочу** добавить новую книгу на свою "книжную полку",
**Чтобы** начать отслеживать ее.

**Критерии приемки:**
*   Я могу указать название и автора книги.
*   По умолчанию книге присваивается статус "Хочу прочитать".
*   После добавления я вижу эту книгу в своем общем списке.

---

### User Story 2: Просмотр списка своих книг

**Как** пользователь,
**Я хочу** видеть все книги, которые я добавил,
**Чтобы** иметь общее представление о своей библиотеке.

**Критерии приемки:**
*   Я вижу список всех своих книг.
*   Для каждой книги в списке отображается ее название, автор и текущий статус.
*   (В будущем) Я могу фильтровать список по статусу ("Читаю", "Прочитана" и т.д.).

---

### User Story 3: Изменение статуса книги

**Как** пользователь,
**Я хочу** изменить статус книги (например, с "Хочу прочитать" на "Читаю"),
**Чтобы** отразить свой прогресс.

**Критерии приемки:**
*   Я могу открыть для редактирования любую книгу из моего списка.
*   Я могу изменить ее статус на один из доступных: "Хочу прочитать", "Читаю", "Прочитана".
*   Новый статус сохраняется и отображается в общем списке.

---

### User Story 4: Оценка и рецензирование прочитанной книги

**Как** пользователь,
**Я хочу** поставить оценку и написать короткий отзыв для прочитанной книги,
**Чтобы** зафиксировать свои впечатления.

**Критерии приемки:**
*   Когда книга имеет статус "Прочитана", я могу добавить/изменить оценку (например, от 1 до 5).
*   Я могу добавить/изменить текстовый отзыв.
*   Оценка и отзыв сохраняются вместе с остальной информацией о книге.

---

### User Story 5: Удаление книги с полки

**Как** пользователь,
**Я хочу** удалить книгу со своей "книжной полки",
**Чтобы** убрать книги, которые мне больше не интересны или были добавлены по ошибке.

**Критерии приемки:**
*   У меня есть возможность удалить любую книгу из списка.
*   После подтверждения книга исчезает из моего списка.
