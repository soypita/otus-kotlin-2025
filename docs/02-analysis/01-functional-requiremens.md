# Функциональные требования

### 1. Управление "Книжной полкой"

1.1. **Создание записи о книге**
    - **Источник требования:** Пользователь сервиса.
    - **Описание требования:** Реализовать возможность добавления новой книги на "книжную полку". Обязательные поля для создания:
        - Название книги (`bookTitle`)
        - Автор книги (`bookAuthor`)
    - При создании записи, ей по умолчанию присваивается статус "Хочу прочитать" (`WANT_TO_READ`).
    - **Приоритет требования:** Высокий.

1.2. **Получение записи о книге по ID**
    - **Источник требования:** Пользователь сервиса.
    - **Описание требования:** Реализовать возможность получить полную информацию об одной конкретной книге из своей "полки" по её уникальному идентификатору.
    - **Приоритет требования:** Высокий.

1.3. **Обновление записи о книге**
    - **Источник требования:** Пользователь сервиса.
    - **Описание требования:** Реализовать возможность редактирования существующей записи. Пользователь может изменить:
        - Статус прочтения (`status`).
        - Оценку (`rating`), если статус "Прочитана".
        - Текстовый отзыв (`reviewText`).
    - **Приоритет требования:** Высокий.

1.4. **Удаление записи о книге**
    - **Источник требования:** Пользователь сервиса.
    - **Описание требования:** Предоставить пользователю возможность удалить книгу со своей "полки".
    - **Приоритет требования:** Средний.

### 2. Поиск и фильтрация

2.1. **Поиск и получение списка книг**
    - **Источник требования:** Пользователь сервиса.
    - **Описание требования:** Обеспечить единый функционал для получения списка книг с "полки" пользователя с возможностью гибкой фильтрации. Если фильтры не указаны, возвращается весь список.
    - **Поддерживаемые критерии фильтрации:**
        - По названию книги (`bookTitle`).
        - По имени автора (`bookAuthor`).
        - По статусу (`status`).
        - По рейтингу (`rating`).
    - **Приоритет требования:** Высокий.

### 3. Управление профилем (в будущем)

3.1. **Регистрация и аутентификация пользователя**
    - **Источник требования:** Пользователь сервиса.
    - **Описание требования:** Реализовать функционал регистрации и входа в систему, чтобы обеспечить персонализацию "книжной полки". В рамках MVP предполагается работа с одним "условным" пользователем.
    - **Приоритет требования:** Низкий (для MVP).

### 4. Уведомления и асинхронные операции (в будущем)

4.1. **Уведомления об активности друзей**
    - **Источник требования:** Пользователь сервиса.
    - **Описание требования:** В будущей версии с социальной составляющей, пользователь должен получать уведомления о действиях друзей в реальном времени (например, "Друг Х дочитал книгу Y и поставил оценку 5"). Это будет реализовано через механизм real-time обновлений.
    - **Приоритет требования:** Низкий (для MVP).

4.2. **Асинхронная обработка событий**
    - **Источник требования:** Разработчик.
    - **Описание требования:** Действия пользователей (оценка книги, добавление в избранное) должны публиковаться как события в шину событий для последующей асинхронной обработки (например, для системы рекомендаций).
    - **Приоритет требования:** Низкий (для MVP).
