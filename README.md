# BookShelf: Сервис для отслеживания книг

Учебный проект курса [Kotlin Backend Developer](https://otus.ru/lessons/kotlin/).
Поток курса 2025-11.

**BookShelf** -- это персональный сервис для ведения списка книг, которые пользователь прочитал, читает или планирует прочитать. Пользователь может ставить оценки и оставлять короткие заметки, формируя свою "книжную полку".
